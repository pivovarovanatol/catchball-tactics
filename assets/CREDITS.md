# Asset credits

## player.glb

Mannequin character and animations from the **Universal Animation Library** (Standard) by
[Quaternius](https://quaternius.com/packs/universalanimationlibrary.html), released under
**CC0 1.0 Universal** (public domain). Thank you, Quaternius.

Trimmed for this project: only the clips used (Idle, Crouch Idle, Walk, Jog, Sprint, Jump Start/Loop/Land),
finger and scale tracks removed, keyframes resampled. Throws, passes and catches are made in code
(`js/view3d.js`) on top of these clips.
